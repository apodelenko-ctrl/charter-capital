USDC-платежи из регулируемого контура / платёжное досье SoF для юрлица / консультация по

**B_private · Тема: «Деньги из РФ для западного банка — мусор? Не обязательно»**
Хук в первой строке: «Для западного банка деньги без понятной биографии — мусор»
(тезис со страницы qualified-clients). Дальше: банк спрашивает не «сколько», а «откуда
и чьи». Строим: SoF/SoW-досье, ВНЖ (Мальта €15 000/год, ОАЭ, Азия), готовый бизнес в ЕС,
недвижимость. Три шага: дайджест t.me/ccapital26 → диагностика 60 сек → ответ на
письмо = NDA-разбор 30 мин. Дисклеймер про санкции/происхождение. Отписка: «отписаться».

Формат B: multipart (plain + HTML). HTML-версия — одна картинка-хук
(деньги с пустой биркой у закрытой двери банка, `ccapital.pro/assets/email/hook-money.jpg`),
хук-заголовок текстом (виден даже при заблокированных картинках), дальше обычный текст
со ссылками. Сегмент A остаётся plain-text — для корпоративных фильтров так надёжнее,
и деловое письмо без вёрстки выглядит естественнее.

## Механика отправки

1. Отправитель: hello@ccapital.pro (Яндекс 360; SPF/DKIM у домена настроены, проверено).
   Нужен пароль приложения Яндекс ID → передать и запускать send.py.
2. Прогрев: дни 1–3 по 15–30 писем (сегмент A), дальше 30–50/день (сегмент B).
   Вся база ~3 недели. Массовый залп запрещён: лимит Яндекса ~500/день, риск блока ящика.
3. send.py: журнал sent.csv (без повторов), unsubscribed.txt, пауза 45–90 с,
   автостоп при SMTP-лимите, --dry-run для проверки.
4. Замер: UTM utm_source=email, utm_campaign=ved|private → Метрика; главный KPI — ответы.
5. Ответившим — созвон/NDA-разбор; отписавшихся — в unsubscribed.txt немедленно.
