# Владелец: переключение в пять шагов

Код подготовлен в [PR #4](https://github.com/apodelenko-ctrl/charter-capital/pull/4). Отдельный сервер не нужен. [Workers Paid](https://dash.cloudflare.com/fd0c7f5f0d6f026a7a3ff5478ab90e09/billing/subscriptions) должен быть Active; повторная покупка не нужна. Полный порядок действий оператора — [CUTOVER.md](CUTOVER.md).

1. **Быть у Mac в согласованное окно.** На 7 октября 2026 согласовано 21:00–22:00 МСК = 18:00–19:00 UTC = 8 октября 01:00–02:00 Бангкок. До окна Mac работает, облачный sender OFF. Если владелец не готов, автоматической остановки не будет. Оператор в окне штатно останавливает единственный Mac sender, отключает автозапуски, делает свежую резервную копию и переносит историю в выключенное облако.

2. **После сообщения оператора «готово к передаче» открыть Терминал на Mac и проверить готовность.** Команда не читает Telegram-секреты и не использует сеть. Для подготовленного checkout:

   ```sh
   cd /Users/ktel25/Documents/Codex/2026-10-06/task-2/cloud-parity-review/infra/cloudflare-sender
   python3 tools/owner_secrets.py --root "$HOME/.local/share/charter-quote-worker" --check-only
   ```

   Должно быть `ready: true`. Сейчас ожидаемо `mac_worker_lock_busy`, пока отправитель работает. При `ready: false` ничего не обходить — передать оператору только `reason`.

3. **В этом же Терминале лично запустить передачу и ввести `ПЕРЕНЕСТИ`.** Вводить коды Telegram, пароли и сами значения не нужно:

   ```sh
   python3 tools/owner_secrets.py --root "$HOME/.local/share/charter-quote-worker" --owner-approved-cutover --transfer-existing-secrets
   ```

   Утилита удерживает Mac lock и через существующий вход Wrangler передаёт текущую session/API-пару напрямую в Cloudflare Secrets. Секреты не печатаются, временные файлы и журналы с ними не создаются. Создаётся версия **без развёртывания**; sender не запускается. При запросе нового входа/прав или ошибке остановиться, не создавать token и не повторять вслепую.

4. **Передать оператору только `version_id`.** Session, API hash, коды и скриншоты с секретами в чат/GitHub не отправлять. Оператор сверяет новую версию, развёртывает её выключенной, проверяет импорт и реальное подключение без публикации. Затем в согласованном окне выпускает и включает одного cloud sender. Если передача или проверка не закончены, включение откладывается.

5. **Закрыть Mac после сообщения об успешной приёмке.** Оператор проверяет первые message_id и сохранённую видимость, A/B, FloodWait/stop и ежечасный отчёт по реальному журналу. Mac-автозапуск остаётся отключённым; приватная резервная копия сохранена для отката. При проблеме сначала останавливают облако и переносят его новую историю обратно — два отправителя одновременно не включают.

Счета: [Cloudflare Invoices](https://dash.cloudflare.com/fd0c7f5f0d6f026a7a3ff5478ab90e09/billing/invoices). Эта инструкция не выполняет покупки, возвраты, отмены подписки или изменения прав.
