# Документы для скачивания

Положите сюда PDF-файлы приложений:

- `prilozhenie-6-akt-zaloga.pdf` — Акт передачи залога (Приложение №6)
- `prilozhenie-7-akt-vzyskaniya.pdf` — Акт взыскания (Приложение №7)

Пути на файлы прописаны в `src/config/data.js` в массиве `documents`.
Чтобы изменить имена файлов или добавить новые документы — отредактируйте `data.js`.
