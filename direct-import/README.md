# Charter Capital — файлы для импорта в Яндекс.Директ

Готовые к загрузке файлы для **Директ Коммандера** (или интерфейса «Управление
через Excel»). Создаются **3 кампании только на Поиске**. В аккаунте Яндекса
ничего не сделано — здесь только файлы для импорта.

> Источник формата: официальная справка Яндекса
> «Формат файла и правила заполнения полей» (Директ Коммандер), проверено 2026.
> https://yandex.ru/support/direct-commander-new/ru/advanced/file-format

## 2. Как загрузить в Директ Коммандер

1. Откройте Директ Коммандер → выберите нужный логин/клиента, получите данные с
   сервера (кнопка **«Получить»**).
2. Вкладка **«Кампании»** → меню **«Импорт»** → **«Из файла»** (или «Из буфера обмена»).
3. Выберите файл `campaign-1-...csv` (затем по очереди 2 и 3) **или** `all-campaigns.csv`.
4. В окне импорта для формата CSV **выберите разделитель полей — «Табуляция»**.
5. Проверьте в окне предпросмотра, что столбцы распознаны правильно (заголовки
   на русском сопоставляются автоматически; при необходимости поправьте вручную).
6. Выберите действие **«Создать новую кампанию»**.
7. После импорта проверьте кампанию и нажмите **«Отправить»** для выгрузки на сервер.

**Альтернатива (без Коммандера):** Директ → «Управление через Excel» → загрузка
файла. Логика полей идентична.

### Соответствие колонок официальному шаблону

В файлах уже стоят официальные заголовки полей вкладки «Тексты», заполнять
вручную ничего не нужно. Расшифровка, что куда идёт:

| Колонка в файле | Поле системы / правило |
|-----------------|------------------------|
| `Название кампании` | Имя кампании (нейминг сохраняется из CSV) |
| `Тип кампании` | `Текстово-графическая` (заполняется только при создании новой кампании) |
| `Минус-фразы на кампанию` | Единые минус-фразы кампании, через запятую. Заполнено в **первой строке** кампании |
| `Название группы` | Имя группы. Заполнено в строке главного объявления группы |
| `Номер группы` | Числовой ID для связи фраз и объявлений с группой (1, 2, 3…) |
| `Доп. объявление группы` | `-` — главное объявление группы; `+` — дополнительное объявление |
| `Фраза (с минус-словами)` | Ключевая фраза. **Фразовое соответствие = в кавычках** `"..."` |
| `Заголовок 1` | ≤ 56 символов |
| `Заголовок 2` | ≤ 30 символов |
| `Текст` | ≤ 81 символа |
| `Ссылка` | URL лендинга с UTM |
| `Отображаемая ссылка` | Display path ≤ 20 символов, без домена |
| `Заголовки быстрых ссылок` | 4 заголовка через `||` |
| `Описания быстрых ссылок` | Описания через `||` |
| `Адреса быстрых ссылок` | URL быстрых ссылок с UTM, через `||` |
| `Уточнения` | Callouts через `||`, ≤ 25 символов каждое |
| `Минус-фразы на группу` | Минус-фразы группы, через запятую (здесь пусто — всё вынесено на кампанию) |

**Структура строк в файле (как в справке):**
- 1-я строка группы: `Доп. объявление группы = -` + название/номер группы +
  1-я фраза + главное объявление + быстрые ссылки + уточнения.
- Следующие строки с фразами: `Доп. объявление группы = -`, заполнена только фраза.
- Дополнительное объявление: `Доп. объявление группы = +`, заполнены только поля
  объявления (заголовки, текст, ссылка, быстрые ссылки, уточнения).

> Если что-то из расширений (быстрые ссылки/уточнения) не подхватится при импорте
> CSV — продублируйте их вручную в Коммандере из блоков ниже (раздел 5 и 6).
> Минус-фразы кампании при необходимости вставляются в свойствах кампании
> (раздел 4).

≤ 25 символов каждое, без непроверяемых обещаний.

> Год основания — 2023 (подтверждён владельцем).

## 7. UTM на конечных ссылках

Единая схема для всех ссылок лендингов (в колонке `Ссылка`):
```
?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```
`{campaign_id}`, `{ad_id}`, `{keyword}` — стандартные **макросы Яндекс.Директа**,
подставляются автоматически при показе. `yclid` сайт дотегивает сам — отдельно
добавлять не нужно.

## 8. Перегенерация файлов

```bash
cd direct-import
python3 build_import.py
```
Скрипт пересоздаёт все CSV и в конце печатает сводку групп и **проверку лимитов**
длины заголовков/текста/display-path.
